# ME3 Core v0.1.214

Legacy Assistant Jobs is retired. Existing jobs stop running when this update is applied, and their definitions, versions, run history, and ingress tables are removed.

Booking reminders remain available through the Booking reminders switch in each site's booking editor. The migration preserves each site's current enabled or paused state before removing the legacy tables. Existing Weekly Review tasks, saved briefings, and Mission Control review history remain readable. Manual Local Executor runs and the campaign email pipeline continue to work.

This release requires D1 migration `0064_retire_legacy_automations`. Apply database migrations as part of the upgrade. Back up an installation before upgrading if you need to retain the retired definitions or run records.
